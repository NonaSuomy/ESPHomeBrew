NetSurf on the ESP32-P4

This is the NetSurf web browser's framebuffer frontend, running as a PAPP. Type an address in the bar at the top: plain http:// sites, files on the card and NetSurf's own pages work. HTTPS is not available yet.

Try

  • about:about: NetSurf's internal pages
  • about:config: its options
  • about:credits and about:licence
  • info.cern.ch: the first web site
  • FrogFind: a search engine for old browsers
  • 68k.news: news in plain HTML
  • file:///sd/roms/netsurf/index.html: your own start page on the card

Controls

  • Touch: tap to click, drag the page to scroll, drag the scroll bars.
  • The keyboard button in the bottom right corner opens an on-screen keyboard.
  • USB mouse: point and click; hold the middle button and move to scroll.
  • USB keyboard: type into the address bar or page; arrows, Page Up/Down, Home/End scroll. F6 or Ctrl-L: new address. F5: reload. Alt+Left/Right: back/forward. Ctrl-+/-/0: zoom.
  • Gamepad: A click, B back, Y reload, Select address bar, Start Enter, L/R page up/down.
  • Menu or Escape held for 3 seconds, or the X button at the top right, quits to the launcher.

Files

NetSurf keeps its files in /sd/roms/netsurf/: Choices (options, in NetSurf's key:value format), Cookies, and optionally Messages or its own copies of default.css, welcome.html and the other built-in resources, which then replace the built-in ones. Create an empty file named verbose there for NetSurf's log in the device log.
